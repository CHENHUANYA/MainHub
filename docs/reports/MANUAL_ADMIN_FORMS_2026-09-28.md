# 管理員使用者與設定頁版面統一

使用者頁將搜尋篩選、新增帳號、批次匯入分區；建立與匯入表單可展開，帳號清單先顯示姓名、帳號、角色、團隊、產線及啟用狀態，編輯欄位另行展開。新增與編輯欄位具可見中文標籤，角色選項及人數摘要中文化，搜尋可匹配中文角色名稱。原始角色代碼、資料欄位與更新 API 保留。

公司設定包改為一致的檔案選擇區與說明字級；系統設定補上標籤關聯並翻譯操作員名稱。稽核紀錄占滿整列，常見事件標題改為中文，時間、執行人員與內容分層呈現。小螢幕改用單欄。
