## 使用方式

記得密碼：登入後按頁首「更改密碼」，輸入目前密碼、新密碼及確認密碼。
舊密碼即為這次操作的身分驗證，不需要另外提供信箱或驗證碼。
更改成功後所有裝置登出，回登入頁以新密碼登入。

忘記密碼：目前沒有郵件、簡訊或其他自助找回管道。請聯絡公司管理員，由管理員透過公司既有方式確認本人身分，
再到「使用者」→ 該帳號「編輯帳號資料」→「協助重設密碼」，設定並私下交付臨時密碼。
原密碼與既有登入立即失效；本人使用臨時密碼登入後，必須設定不同的個人密碼，才能進入系統。
管理員不能藉此功能繞過自己的舊密碼驗證；自己的密碼一律走頁首入口。

所有新建立帳號（逐筆新增及 Excel 匯入）和新部署管理員，首次登入也會要求設定個人密碼。
既有帳號不會因這次更新被重設或強制改密碼。
