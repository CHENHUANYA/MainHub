# 維修人員補充退回知識

管理員已將工單 `c9883d44` 退回補充，但維修人員看不到這筆已驗證工單。原有 JSON 權限及 PostgreSQL 分頁都排除已完成、已驗證工單，前端預設看板也隱藏已驗證狀態。「已驗證封存」選項讀取的是實際封存檔案，無法顯示這筆仍在主資料庫的紀錄。

## 修正

- 維修人員僅能查看及補充指派給本人、已完成或已驗證、且知識審核為退回補充的紀錄。其他人的工單、未退回的結案紀錄與取消工單維持原有權限。
- 工作台預設看板增加「待補充知識」欄，保留原工單狀態並顯示審核備註。
- 補充時僅可更新根本原因、實際維修動作、處理結果、備註，必須帶目前版本。禁止改變工單狀態、負責人、設備或驗證身分；必填內容與實際變更均須通過檢查。
- 按「補充並重新送審」後回到待審核，保留原驗證紀錄，不變更已結案問題，不自動寫入知識庫。重新送審後，維修人員的補充例外權限結束。
- 儲存錯誤直接顯示在表單並保留輸入；送出期間防止重複儲存及關閉。
