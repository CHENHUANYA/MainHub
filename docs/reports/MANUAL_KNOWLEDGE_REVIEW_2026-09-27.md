# 管理員知識審核表單修正

人工測試中，「退回補充」依賴原生 `window.prompt`，內嵌瀏覽器未顯示输入框，導致按鈕看似沒有反應。同組「核准」與「不採用」也依賴原生對話框，統一改為頁面內確認區。

- 顯示工單編號、動作說明、補充要求或選填的不採用原因，以及確認／取消按鈕。
- 退回補充必須填寫原因；送出期間防止重複送出、切換對象及取消。失敗保留原因與錯誤訊息，成功關閉表單並更新清單。
- 沿用知識審核 API、登入權限與工單版本檢查；增加宣告式事件白名單及前端資源版本。
- 未代替使用者審核工單。瀏覽器測試攔截三種審核 POST 並模擬版本衝突，驗證前後工單清單資料完全相同。

18 項相關 JavaScript 測試、36 項前端資源／契約檢查通過。獨立背景 Edge 在實際部署驗證三種表單、空白原因、取消、錯誤保留、動作與版本參數，無原生對話框或頁面程式錯誤，並核對桌面／手機版面。成功送出後的行為由單元測試驗證，實際業務審核仍待使用者操作。

CNC 測試站更新為 `mainthub:manual-knowledge-review-20260927`，以統計卡片修正版映像為基礎；就緒及 226 份部署檔案完整性檢查通過。部署前副本、修正清單、截圖及檢查結果保存在 `outputs/manual-knowledge-review-20260927/`。新版交付 ZIP 尚待後續統一打包。
