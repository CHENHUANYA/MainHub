# 2026-09-29 安裝包更新說明

版本：`mainthub-company-template-20260929-password`（包含 9/28 審核修正及 9/29 密碼功能與人工測試修正）。
本版整合 9/26 精修版後已由使用者確認的管理員審核流程與介面修正。
安裝入口為 [公司導入 SOP](COMPANY_DEPLOYMENT_SOP_ZH_TW.md)。

## 密碼與登入

- 四角色頁首可自行更改密碼，須驗證目前密碼；成功後撤銷所有登入並以新密碼重新登入。
- 管理員協助重設提供臨時密碼，使用者下次登入須自行設定個人密碼；管理員更改自己的密碼仍須輸入目前密碼。
- 單筆新增與批次新增帳號一致，首次登入須設定個人密碼。
- 登入頁說明、表單及忘記密碼區的中文字體一致；登入失敗、限流、服務異常及首次改密碼提示中文化。
- 取消清空欄位，儲存中防止重複提交；桌面與手機可操作。
- 未設定郵件或簡訊驗證，忘記密碼仍由管理員確認身分後提供臨時密碼。
- 測試步驟及人工結果見 [密碼功能測試](PASSWORD_ACCEPTANCE_ZH_TW.md)。人工回報不取代本包的乾淨安裝驗證。

## 審核與維修流程

- 管理員可在頁面內填寫退回補充要求、確認核准入庫或不採用。
- 維修人員可在「待補充知識」找到指派給自己的退回紀錄，修改根本原因、實際維修動作、處理結果及備註後重新送審。
- 補充時保留原工單驗證狀態與驗證人員；重新送審後等待管理員核准才入庫。
- 審核詳情完整顯示上述四項內容與補充備註；不採用保留維修紀錄。
- 主管退回重工使用頁內原因表單；儲存中避免重複送出，失敗時保留輸入並顯示錯誤。

## 介面整理

- 統一公司名稱頁首、登入表單、管理員導覽與品質卡片。
- 使用者管理分開搜尋、新增及批次匯入，欄位及角色中文化，編輯表單可展開。
- 公司設定與稽核紀錄版面統一；歷程中文化並修正重複顯示。
- 原回答追溯、知識審核詳情與各角色頁面支援小螢幕排版。

## 安裝及驗證範圍

來源 ZIP 包含程式、SOP、這份更新說明及正式驗收空白表；不含帳密、公司資料、PDF、資料庫、映像或模型。
